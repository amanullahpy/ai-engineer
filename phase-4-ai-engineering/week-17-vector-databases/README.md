# Week 17: Vector Databases & RAG

## 📚 Concepts in this Module
- **[Vector Databases](./01-vector-databases-intro)**: Understand how semantic embeddings are index-searched using specialized databases (Pinecone, ChromaDB).
- **[Retrieval-Augmented Generation (RAG)](./02-rag-architecture)**: Combine document retrieval databases with generative LLMs to answer domain-specific questions.


## 🛠️ Weekly Project
