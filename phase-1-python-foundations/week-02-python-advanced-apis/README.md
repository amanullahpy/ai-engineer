# Week 2: Advanced Python & APIs

## 📚 Concepts in this Module
- **[Virtual Environments & Package Management](./01-virtual-environments-pip)**: Understand dependency isolation in Python using venv, and manage external packages with pip.
- **[Consuming Public APIs in Python](./02-consume-apis)**: Learn to perform HTTP calls, handle headers, parse JSON payloads, and manage API exceptions.
- **[NumPy & Pandas Basics](./03-numpy-pandas-basics)**: Get introduced to array manipulation with NumPy and basic tabular data handling with Pandas.


## 🛠️ Weekly Project
- **[Consume Public APIs with Python](./projects/consume-public-apis)**: Write a Python script that calls a public REST API (like GitHub API, OpenWeather, or JSONPlaceholder) to fetch, process, format, and display data, handling errors gracefully.
